# No emojis in output

No emoji appears anywhere in generated output or in the authoring guidance
that produces it - plain text labels only. This is a hard constraint on
templates and skill instructions alike rather than a style preference, so that
output stays legible in terminals, diffs, screen readers, and print without
depending on font coverage.
