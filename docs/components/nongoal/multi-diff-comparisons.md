# Multi-diff comparisons, timelines, and PDF

explain-diff explains one diff. Comparing several diffs side by side,
rendering history timelines across a series of changes, and PDF generation
beyond what the print stylesheet already produces are all excluded. Excluded
as YAGNI: each is a distinct product with its own navigation and state, and
the print CSS already covers the one export anyone actually asked for.
