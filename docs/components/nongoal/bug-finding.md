# Bug-finding and review judgments

explain-diff explains intent and implications; it does not judge code or hunt
for bugs. A guide says what changed, why, which decisions are load-bearing and
what remains open - it never reports a defect or rates quality. Excluded
because mixing the two changes how the output is read: a document that
sometimes judges invites the reader to treat silence as approval, and code
review is a separate job with a separate standard of evidence.
