# A host-abstraction framework

Cross-compatible packaging will make the existing Grimore workflows install,
load, and describe equivalent actions in Claude Code and Codex, but it will
not introduce an abstraction layer that models every tool, invocation syntax,
or interaction primitive across agent harnesses. That redesign is excluded
because the current portability gaps are narrow enough to remove directly,
while a framework would add a maintained compatibility surface before the
project has evidence that more than targeted wording and provenance changes
are needed.
