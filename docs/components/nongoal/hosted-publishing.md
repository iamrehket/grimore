# Hosted publishing of change guides

explain-diff writes a self-contained local HTML file and does not publish it
to any hosted surface; hosted publishing may be added later as an option, but
local HTML stays canonical. Excluded because a self-contained file needs no
account, no network, and no retention policy - and a change guide routinely
embeds code that has not been reviewed for disclosure.
