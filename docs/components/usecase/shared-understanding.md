# Shared understanding before the next iteration

A human and an agent finish a change holding different mental models of it,
and the next iteration starts from that mismatch. explain-diff closes the gap
before the loop repeats: one guide states what the system does now that it did
not before, which decisions are load-bearing, what the implications are, and
which questions remain open - then helps the human compose the reply that
starts the next round.
