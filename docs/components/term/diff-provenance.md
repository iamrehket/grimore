**Diff provenance**: whether an explanation's rationale was stated or
inferred. A warm diff is the change made in the current session, where
rationale comes from conversation context and is labelled stated. A cold diff
is an arbitrary range, branch, or pull request, where intent is
reverse-engineered from the code and labelled inferred. The page shows which
it was, so a reader never mistakes a reconstruction for a report.

_Avoid_: diff mode.
